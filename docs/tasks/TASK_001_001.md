## Description

Research and document the visual characteristics of TikTok-style captions to inform implementation. This includes analyzing:

- Color schemes and gradients

2. Document common patterns:

3. Find ASS/SSA equivalent styling tags
4. Create reference document with examples
5. Identify any limitations in ASS format
